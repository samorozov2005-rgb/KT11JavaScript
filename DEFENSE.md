# Подготовка к защите ThriveTalk

## 1. Что такое React

React — JavaScript-библиотека для построения интерфейсов из компонентов. В этом проекте React получает JSX из `src/App.jsx`, создаёт дерево элементов и отображает его внутри `<div id="root">` из `index.html`.

Точка запуска — `src/main.jsx`:

```jsx
ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode><App /></React.StrictMode>,
);
```

## 2. Зачем нужны компоненты

Компонент — функция, которая возвращает часть интерфейса. Деление позволяет независимо читать, изменять и переиспользовать части страницы. Например, `WhyThrive.jsx` отвечает только за голубую секцию, а `Footer.jsx` — только за нижний блок.

Каждая самостоятельная секция находится в своей папке и имеет собственный CSS Module.

## 3. Как работает App.jsx

`App.jsx` импортирует основные секции и размещает их в порядке макета:

```jsx
<Header />
<Hero />
<main>
  <WhyThrive />
  <About />
  <Services />
  <Programs />
  <Benefits />
  <StorySection />
  <ContactSection />
</main>
<Footer />
```

`App` не содержит разметку всех секций, поэтому корневой файл остаётся коротким и понятным.

## 4. Дерево компонентов

Файл `component-tree.png` показывает, что корнем является `App`, ниже расположены основные секции, а ещё ниже — вложенные повторяемые компоненты. Оранжевым отмечены компоненты, которые получают данные через props и используются многократно.

## 5. Props

Props — входные данные компонента. Они передаются родителем и позволяют одному компоненту отображать разное содержимое.

Пример `ProgramCard.jsx`:

```jsx
function ProgramCard({ title, color, image }) {
  // title, color и image пришли из Programs
}
```

В `Programs.jsx` данные передаются так:

```jsx
<ProgramCard key={program.id} {...program} />
```

Оператор `{...program}` передаёт поля объекта как отдельные props.

## 6. Зачем переиспользуемые компоненты

`ServiceCard`, `ProgramCard` и `BenefitCard` описывают внешний вид карточки один раз. Если изменить разметку или стиль карточки, изменение применяется ко всем экземплярам. `Button` тем же способом обеспечивает единый вид CTA в четырёх секциях.

## 7. Для чего нужен .map()

`.map()` перебирает массив и возвращает новый массив JSX-элементов. В `Services.jsx` четыре объекта превращаются в четыре `ServiceCard`, в `Programs.jsx` — шесть объектов в шесть `ProgramCard`, а в `Benefits.jsx` — шесть объектов в шесть `BenefitCard`.

Это отделяет данные от разметки и устраняет копирование одинакового JSX.

## 8. Зачем React нужен key

`key` помогает React понять, какой элемент списка изменился, добавился или удалился. В проекте используется стабильное поле `id`, например `key={benefit.id}`. Индекс массива не используется, потому что он хуже описывает идентичность элемента.

## 9. Что такое CSS Modules

CSS Module — обычный CSS-файл, классы из которого при сборке получают уникальные имена. Компонент импортирует его как объект:

```jsx
import styles from './Hero.module.css';
<section className={styles.hero}>...</section>
```

Поэтому `.hero` из `Hero.module.css` не конфликтует с классами других компонентов.

## 10. App.css и ComponentName.module.css

`src/App.css` содержит глобальные вещи: CSS reset, переменные цветов, базовый шрифт, поведение `body`, ссылок, изображений и фокуса.

`ComponentName.module.css` содержит только локальное оформление одного компонента. Например, размеры карточки программы находятся в `ProgramCard.module.css`, а стили навигации — в `Header.module.css`.

## 11. Flexbox и Grid

CSS Grid подходит для двумерных сеток. Он используется:

- в `Services.module.css` — 4 колонки карточек;
- в `Programs.module.css` — сетка 3 × 2;
- в `Benefits.module.css` — сетка 3 × 2;
- в `Footer.module.css` — изображение и информационные колонки.

Flexbox подходит для расположения элементов в одном направлении. Он используется в `Header.module.css` для навигации, в `Hero.module.css` для CTA и в нескольких секциях для вертикального расположения контента.

## 12. Как работают импорты

Компонент экспортируется по умолчанию:

```jsx
export default Hero;
```

Другой файл получает его через import:

```jsx
import Hero from './components/Hero/Hero.jsx';
```

Vite начинает с `index.html`, загружает `src/main.jsx`, затем проходит по цепочке импортов и собирает все компоненты и стили.

## 13. Как React собирает страницу

`main.jsx` создаёт React root и вызывает `App`. `App` вызывает функции-компоненты секций. `Services`, `Programs` и `Benefits` дополнительно создают карточки через `.map()`. Результат — единое React-дерево, которое React преобразует в DOM браузера.

## 14. Vite и React — не одно и то же

React отвечает за компоненты и обновление интерфейса. Vite — инструмент разработки и сборки: запускает dev-сервер, обрабатывает JSX и CSS Modules, оптимизирует файлы и создаёт папку `dist`.

Команда `npm run dev` запускает Vite в режиме разработки, а `npm run build` создаёт production-сборку.

## 15. Адаптивность и доступность

Media queries переключают 4- и 3-колоночные сетки в 2 и 1 колонку. На мобильном изображение и текст идут друг за другом, а desktop-навигация заменяется кнопкой меню.

Навигация имеет `aria-label`, кнопка меню — `aria-expanded`, изображения — `alt`, а `:focus-visible` показывает клавиатурный фокус.

## 16. Как запустить и проверить

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

Успешный `npm run build` должен вывести строки `modules transformed` и `built`, а в корне появится папка `dist`.

## 17. Короткий план устного ответа

1. Показать `component-tree.png` и `App.jsx`.
2. Открыть `Services.jsx`: объяснить массив, `.map()`, props и `key`.
3. Открыть `ServiceCard.jsx` и `ServiceCard.module.css`: показать связь компонента и локальных стилей.
4. Показать media queries в `Services.module.css` или `Hero.module.css`.
5. Запустить `npm run dev`, проверить якоря и мобильное меню.
6. Выполнить `npm run build` и показать успешную сборку.
